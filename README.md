About the Project
Development of a dynamic website concept for Delícias Gourmet, a food truck business, with the goal of expanding product visibility, making it easier for customers to place orders, and proposing an administrative dashboard to improve order and product management.

My Contribution
I was responsible for creating and organizing the project in Figma. UI design decisions were made collaboratively with my team and the client.

Project Goals
Expand the online visibility of the food truck's products.
Make it easier for customers to explore products and place orders.
Propose an administrative area for managing orders and products.
Translate the client's needs into a digital website concept.
